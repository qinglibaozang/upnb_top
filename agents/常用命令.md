| 命令 | 用途 |
|---|---|
| `pnpm dev` | 启动开发服务器（前台，配合 `astro dev --background` 后台模式） |
| `pnpm build` | 生产构建（提交前如改动代码，先构建验证） |
| `pnpm preview` | 预览生产构建产物 |
| `pnpm preview:local` | 本地静态预览（`serve-preview.mjs`，含 woff2/webp/avif MIME 与路径安全检查） |
| `npx tsc --noEmit` | 类型检查（注意：项目存在既有 tsc 错误，见下） |

**已知约束**：
- pre-commit 钩子会运行 `tsc --noEmit`；项目存在与本次改动无关的既有类型错误（`astro.config.mjs` 隐式 any、node_modules 内 starlight 类型），**提交时统一用 `--no-verify` 绕过**（用户已确认总是直接绕过，无需再询问，见 AGENTS.md Git 规范）。
