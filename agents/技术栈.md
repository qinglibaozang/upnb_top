## 技术栈

- **Astro + Starlight**（文档站框架）+ **pnpm** + **TypeScript**（严格模式）
- 布局：Starlight 原生布局 + 自有 `zh.css` 设计系统；`starlight-sidebar-topics` 分类切换插件（依赖保留，但**当前已在 `astro.config.mjs` 中注释禁用**——临时关闭分类切换，查看默认扁平侧边栏效果）
- 搜索：Pagefind 中文分词增强（`@node-rs/jieba` 构建端分词 + `jieba-wasm` 浏览器端查询分词）
- 客户端脚本：`src/scripts/zh-optimize.ts`（盘古之白、全角标点间距、侧边栏数字前缀剥离、搜索跳转高亮、hero 标题逐字动画、回到顶部按钮、TOC 概述移除）

**版本策略：保持稳定，不追新。** 以当前锁定版本为准（见 `package.json` / `pnpm-lock.yaml`），除非用户明确要求，不做升级；升级前必须经用户确认，并说明升级理由与影响面。

## 排版体系与中文处理

- **排版体系**：`src/styles/zh.css` 定义字号层级（H1 30px / H2 24px / H3 20px / H4 16px，正文 **16px** 行高 1.7、代码/表格 13px）、字体栈（`--sl-font` 覆盖主题）、导航/内容双层级。
- **中文处理**：`src/scripts/zh-optimize.ts` 实现盘古之白（中英文自动空格），`spacingText` 为纯函数，`PlaceholderReplacer` 保护代码片段/反引号内容不被处理；另有全角标点与汉字间距（`splitPunctuation` 纯函数 + `.zh-punct` 样式）。
